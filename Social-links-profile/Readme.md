# Social Links Profile

A simple and responsive social links profile page built using HTML and CSS.

This project allows users to display their profile information along with links to their social media and professional profiles.

## ✨ Features

- Responsive profile card
- Circular profile image
- User name and location
- Short profile description
- Social media and professional profile links
- Clean and minimal dark-themed UI
- Hover/active styling for social links
- Responsive layout for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts – Inter
