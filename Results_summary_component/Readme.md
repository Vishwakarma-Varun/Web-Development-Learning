# 📊 Results Summary Component

A clean and responsive **Results Summary Component** built with HTML and CSS as part of a Frontend Mentor challenge.

The project focuses on recreating a results summary interface with category-based scores, icons, responsive layout, and a modern visual design.

## ✨ Features

- 📱 Responsive design
- 🎨 Clean and modern UI
- 📊 Results displayed by category
- ⚡ Fast and lightweight
- 🖼️ Category-specific SVG icons
- 📐 Responsive layout using CSS
- 🎯 Structured and semantic HTML
- 🖥️ Works across different screen sizes
