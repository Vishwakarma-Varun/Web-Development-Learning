# Frontend Mentor - Recipe Page Solution

This is my solution to the **Recipe Page Challenge** from Frontend Mentor. The goal of this project was to build a responsive recipe page that closely matches the provided design while practicing HTML and CSS fundamentals.

## 🚀 Built With

- HTML5
- CSS3

- Semantic HTML
- Responsive Design
- CSS Box Model
- CSS Pseudo-elements (`::marker`)
- Google Fonts (Outfit & Young Serif)

## 📚 What I Learned

During this project I practiced:

- Creating responsive layouts using `max-width`
- Using Flexbox for page layout
- Styling ordered and unordered lists
- Working with HTML tables
- Using Google Fonts
- Understanding the difference between `margin` and `padding`
- Styling list markers with `::marker`
- Building responsive images using `width: 100%`
